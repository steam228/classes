Como faço um padrão com um ciclo for?
Usa um for para repetir a mesma forma, mudando a posição em cada volta: for (let i = 0; i < 10; i++) { ellipse(i * 40, 200, 30); } Está em Aula 1 — Código Criativo I, nos conceitos introduzidos.
