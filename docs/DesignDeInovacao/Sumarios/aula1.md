# Aula 1 — Código Criativo I

## Data

**25 de setembro de 2026** (6ª feira)

## Sumário

- Apresentação da UC e do docente
- Estrutura do semestre: blocos temáticos e workshops
- Relação com Design de Produto e Interação I (terças-feiras)
- Introdução ao código criativo: o código como ferramenta de design
- Primeiros passos com Processing / p5.js
- Exercício: formas primitivas, repetição, cor
- Interatividade com `mouseX` / `mouseY`

Nos exercícios e nas entregas usamos **p5.js no VSCode**, a partir do template base de p5.js — ver [Código Criativo com P5.js](../../Recursos/CodigoCriativocomP5JS.md).
