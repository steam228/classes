# BLE

## Understanding BLE Data Packing

Bluetooth Low Energy (BLE) allows devices to communicate by sending small packets of data. When using the ESP32 with C++, you can pack data into these packets effectively.

### Data Structure

BLE uses a hierarchical structure for data transmission, which includes:

- **Profile**: A collection of services for a specific use case.
- **Service**: A group of related characteristics.
- **Characteristic**: Contains the actual data values.
- **Descriptor**: Provides metadata about the characteristic.

### Packing Data

To pack data for BLE on the ESP32, follow these steps:

1. **Define UUIDs**: Each service and characteristic needs a unique identifier (UUID).
    
    ```cpp
    #defineSERVICE_UUID"4fafc201-1fb5-459e-8fcc-c5c9c331914b"
    #defineCHARACTERISTIC_UUID"beb5483e-36e1-4688-b7f5-ea07361b26a8"
    ```
    
2. **Create a BLE Server**: Initialize the BLE server and create a service.
    
    ```cpp
    BLEServer*pServer=BLEDevice::createServer();
    BLEService*pService= pServer->createService(SERVICE_UUID);
    ```
    
3. **Create Characteristics**: Define characteristics with properties like read and write.
    
    ```cpp
    BLECharacteristic *pCharacteristic = pService->createCharacteristic(
        CHARACTERISTIC_UUID,
        BLECharacteristic::PROPERTY_READ | BLECharacteristic::PROPERTY_WRITE
    );
    ```
    
4. **Set Data**: Pack your data into the characteristic. You can use various data types, such as strings or integers.
    
    ```cpp
    uint32_t dataValue = 12345; // Example data
    pCharacteristic->setValue((uint8_t*)&dataValue, sizeof(dataValue));
    
    ```
    
5. **Start Advertising**: Make the service available for connections.
    
    ```cpp
    pService->start();
    BLEAdvertising *pAdvertising = pServer->getAdvertising();
    pAdvertising->start();
    ```
    

### Example Code Snippet

Here’s a simple example of how to pack and send a `uint32_t` value:

```cpp
#include <BLEDevice.h>
#include <BLEUtils.h>
#include <BLEServer.h>

#define SERVICE_UUID "4fafc201-1fb5-459e-8fcc-c5c9c331914b"
#define CHARACTERISTIC_UUID "beb5483e-36e1-4688-b7f5-ea07361b26a8"

void setup() {
   Serial.begin(115200);
   BLEDevice::init("ESP32BLE");
   BLEServer *pServer = BLEDevice::createServer();
   BLEService *pService = pServer->createService(SERVICE_UUID);
   BLECharacteristic *pCharacteristic = pService->createCharacteristic(
       CHARACTERISTIC_UUID,
       BLECharacteristic::PROPERTY_READ | BLECharacteristic::PROPERTY_WRITE
   );

   uint32_t dataValue = 12345; // Example data
   pCharacteristic->setValue((uint8_t*)&dataValue, sizeof(dataValue));
   pService->start();
   BLEAdvertising *pAdvertising = pServer->getAdvertising();
   pAdvertising->start();
}

void loop() {
   delay(2000);
}
```

This code initializes a BLE server, creates a service and characteristic, packs a `uint32_t` value, and starts advertising. Adjust the data type and values as needed for your application.
