## Notas da Aula

### (com)FORMA — visão geral

O projeto parte de um objeto pessoal (plástico ou cerâmico) para desenvolver um produto modular cuja forma integra fragmentos do original. O molde é a ferramenta central do processo criativo. O projeto inclui também o desenvolvimento de uma componente de interface (digital ou física).
