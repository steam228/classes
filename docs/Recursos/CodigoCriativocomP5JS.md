# Configuração Base

## Configuração inicial (só uma vez)

### 1. Instalar VSCode

Descarregar e instalar: [code.visualstudio.com](https://code.visualstudio.com/)

### 2. Criar conta GitHub

Registar em: [github.com](https://github.com/)

### 3. Instalar a extensão Live Server no VSCode

![](attachments/Screenshot%202026-10-02%20at%2008.59.37.png)

### 4. Instalar GitHub Desktop

Descarregar em: [desktop.github.com](https://desktop.github.com/)

## Workflow — criar um novo projeto

![](attachments/WorkflowparaconfigdecadaRepo.mp4)

Cada vez que queres começar um novo projeto P5.js:

**1.** Ir ao repositório template:
[github.com/steam228/BasicP5jsExample](https://github.com/steam228/BasicP5jsExample)

**2.** Clicar em **"Use this template"** → **"Create a new repository"**

![](attachments/01.jpeg)
![](attachments/02.jpeg)

**3.** Dar um nome ao repositório e criar

![](attachments/3.jpeg)
![](attachments/4.jpeg)

**4.** Clicar em **"Open with GitHub Desktop"** (ou clonar pela app do GitHub Desktop)

![](attachments/Screenshot%202026-10-02%20at%2009.09.45.png)
![](attachments/Screenshot%202026-10-02%20at%2009.11.46.png)

!!! warning "Atenção"
    Escolher bem a pasta de destino — é lá que o projeto vai ficar.

**5.** Abrir a pasta no VSCode e editar o `sketch.js`
